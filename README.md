# 一餐 Android

一餐是一款离线可用的 Android 菜谱 App。它支持统一关键词搜索、收藏、最近浏览、个人菜谱管理、完整数据备份，以及通过 GitHub Releases 检查并安装更新。

## 当前开发版

- 依据[中餐菜谱补完计划](https://laocp.tech/)的公开老菜谱索引，完善已有同名菜的食材用量并增加书籍、页码参考入口。
- 不新增菜谱，不替换隋坡等原来源视频和做法；网站补充的数值统一显示“老菜谱参考”。

## 1.9.0 功能

- 底部导航调整为“发现 / 菜谱库 / 我的”；收藏、最近、自建菜谱和收集箱集中在菜谱库，减少主入口浪费。
- 支持从视频应用或相册通过 Android 分享菜单发送链接、文案和最多 6 张配方截图到一餐。
- 配方截图使用随 APK 提供的中文模型在本机识别，不上传图片、不下载整段视频，也不自动读取剪贴板。
- 分享结果可先存入收集箱，也可自动提取菜名、食材、用量、步骤、Tips 和来源链接后进入三步编辑器复核。
- 收集箱进入完整备份和合并恢复；未整理内容与正式个人菜谱分开保存。
- Release APK 压缩原生识字库，保留完整离线识字和四种 CPU 架构兼容，下载体积较未压缩构建减少约一半。

## 构建

要求：JDK 17 或更高版本、Android SDK 35。

1. 复制 `signing.properties.example` 为 `signing.properties`。
2. 将 `storeFile` 指向私下保存的连续性签名密钥，填写密码。不要把密钥或密码提交到 Git。
3. 使用 Android Studio 打开本目录，或运行：

```powershell
.\gradlew.bat testDebugUnitTest lintDebug assembleDebug
.\gradlew.bat lintRelease assembleRelease
node --test tests/app-core.test.js
```

正式 APK 位于 `app/build/outputs/apk/release/app-release.apk`。

## 发布更新

创建标签格式为 `v1.9.0` 的 GitHub Release，并上传：

- `YiCan-1.9.0.apk`
- `YiCan-1.9.0.apk.sha256`
- `YiCan-Android-Source-1.9.0.zip`
- `update.json`

`update.json` 格式：

```json
{
  "schemaVersion": 1,
  "versionCode": 15,
  "versionName": "1.9.0",
  "apkUrl": "https://github.com/why685/yican-android/releases/download/v1.9.0/YiCan-1.9.0.apk",
  "apkUrls": [
    "https://gh-proxy.org/https://github.com/why685/yican-android/releases/download/v1.9.0/YiCan-1.9.0.apk",
    "https://github.com/why685/yican-android/releases/download/v1.9.0/YiCan-1.9.0.apk"
  ],
  "sha256": "d5f515c1b6e388cf8a1d31e21b93504d046556b5bada1ebd27bb20adf5fa09d5",
  "releaseNotes": "视频和配方截图快速收集、离线识字、菜谱库整合及安装包减重"
}
```

应用只接受 GitHub 原始地址或内置受信任加速域名中、指向该仓库 Release 路径的 HTTPS APK，并要求 APK 包名、版本号和签名与当前应用一致。普通 Android 应用不能静默更新，校验通过后仍需用户在系统安装界面确认。

仓库根目录同时保留当前 `update.json`，供 jsDelivr 备用检查线路读取。每次发布后应清理 `@main/update.json` 与 `@latest/update.json` 的 CDN 缓存。

## 菜谱 JSON

传统导入格式的必填字段为 `name`、`ingredients` 和 `steps`；可选字段包括 `time`、`difficulty`、`description`、`flavors`、`source`、`video`、`emoji` 和 `tips`。步骤支持 `[标题, 描述, durationSeconds?, videoTimestampSeconds?]`，计时时长范围为 1–14,400 秒；旧字符串、二元素数组和对象步骤仍可导入。完整备份继续使用 `formatVersion: 1`，恢复时合并并去重，不覆盖现有个人数据。
